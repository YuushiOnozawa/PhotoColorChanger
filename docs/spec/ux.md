# PhotoColorChanger UX仕様

## 状態

承認済み

## レイアウト

- Canvasを中央に配置します。
- ツール・設定パネルと色変更履歴パネルを分離します。
- CSS Gridなどで、ツールと履歴をCanvasの左右どちらにも置けるようにします。
- 3領域を独立した構造にし、将来は縦積みや折りたたみに変更できるようにします。
- ラベルとメッセージは日本語にします。

## 画像読み込み

- ファイル選択ボタンとドラッグ＆ドロップ領域を提供します。
- 選択したファイル名と実際の画像サイズを表示します。
- 新しい画像で編集内容が失われる場合は、差し替え前に確認します。
- 未対応、破損、サイズ超過には対処方法付きのメッセージを表示します。

## Canvas操作

- 最初は表示領域に合わせて画像全体を表示します。
- マウスホイールでカーソル位置を中心にズームします。
- ドラッグ、または可能ならSpace＋ドラッグでパンします。
- 全体表示へ戻す操作を提供します。
- ズームとパンの状態に関係なく、ブラシ座標を正しく対応させます。

## 選択とプレビュー

- 許容範囲、変更後の色、塗装強度、マスク編集に対して結果をライブ更新します。
- 選択マスクのオーバーレイを切り替えられます。
- 変更前画像を一時表示する比較操作を提供します。
- 追加／除外モード、サイズ、硬さ、許容範囲を明確に表示します。

## 色変更

- 色面、色相操作、HEX／RGB入力を持つSketch風カラーピッカーを使います。
- 画像データを保存せず、最近使った色だけを少数表示します。
- 履歴項目に変更後の色、強度、表示状態、編集・表示切替・削除・並べ替え操作を表示します。
- 現在編集中の変更を明確に示します。

## Undo／Redo

- 色変更とブラシストロークをUndo／Redoできます。
- ボタンと `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` に対応します。
- Undo状態をブラウザの永続ストレージへ保存しません。

## 書き出し

- PNG／JPEGを選択できます。
- JPEG選択時だけ品質を表示します。
- ダウンロード前に生成ファイル名を表示します。
- ダウンロード画像は、現在表示している、必要に応じて縮小済みの解像度であることを説明します。
