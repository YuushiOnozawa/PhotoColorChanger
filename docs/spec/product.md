# PhotoColorChanger 製品仕様

## 状態

承認済み

## 目的

PhotoColorChangerは、プラモデル写真の塗装後イメージを確認するための、日本語ブラウザサイトです。ユーザーは写真を1枚読み込み、色を選択・調整し、結果をダウンロードできます。

## 対象と制約

- 初期版の対象はPCブラウザです。
- 将来のレスポンシブ表示とタッチ操作を妨げないレイアウトにします。
- 実装はTypeScriptとReactを使用します。
- GitHub Pages上の静的サイトとして公開します。
- バックエンドは使用せず、画像をアップロードしたりサーバーへ保存したりしません。
- 初期対応形式はJPEG、PNG、WebPです。
- HEIC対応は将来拡張です。
- 長辺4096pxを超える画像は編集前に自動縮小し、縮小したことを表示します。
- 初期版のUIとメッセージは日本語のみです。

## 基本操作

1. ファイル選択またはドラッグ＆ドロップで画像を読み込みます。
2. 編集中なら、破棄確認後に画像を差し替えます。
3. 画像をCanvasへ表示します。
4. クリック地点の周辺から元色の代表値を取得します。
5. 画像全体から近似色を選択します。
6. 許容範囲を調整し、追加／除外ブラシでマスクを補正します。
7. 変更後の色と塗装強度を指定します。
8. ライブ結果、マスク、変更前画像を確認します。
9. 必要に応じて別の色変更を追加します。
10. 変更を編集、表示切替、削除、並べ替えします。
11. PNGまたはJPEGとしてダウンロードします。

## 初期版に含める機能

- 1編集セッションにつき1画像
- 許容範囲を調整できる画像全体の近似色選択
- 1つの変更に複数の離れた領域を含める機能
- サイズと硬さを調整できる追加／除外マスクブラシ
- HEXとRGB入力に対応したSketch風カラーピッカー
- 塗装強度の調整
- 元画像の相対的な陰影、ハイライト、質感の維持
- ライブプレビュー、マスク表示、変更前後比較、ズーム、パン
- 色変更とブラシ操作のUndo／Redo
- 90度の左右回転
- PNG／JPEG書き出しとJPEG品質調整

## 初期版の対象外

- トリミング
- 任意角度の回転
- 完全なレイヤーパネル
- 線画抽出
- HEICデコード
- メーカー塗料データベース連携
- プロジェクト保存、セッション復元、画像永続化
- 複数画像タブ、バッチ処理

## プライバシーとライフサイクル

- 画像、マスク、描画結果、編集履歴はメモリ上だけに保持します。
- ページの再読み込みや終了時に画像関連データを破棄します。
- `localStorage` に保存できるのは、最近使った色やUI設定など画像を含まない情報だけです。
- ユーザー画像をログ出力、送信、永続化しません。
