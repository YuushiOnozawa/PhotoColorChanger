# 画像処理仕様

## 状態

動作仕様は承認済み。実装方式は未確定です。

## 読み込みと正規化

- ブラウザでデコードできるJPEG、PNG、WebPを受け付けます。
- 未対応または壊れたファイルは、日本語の対処方法付きエラーで拒否します。
- 写真の向きを読み込み時に正しく反映します。
- 長辺が4096pxを超える場合は編集前に縮小し、縮小後のサイズを表示します。
- 元画像をアップロードせず、バックエンドも要求しません。

## 元色の取得

- 1ピクセルだけでなく、クリック周辺の小範囲から代表色を取得します。
- 可能な場合は、カーソル付近に拡大したスポイト表示を出します。
- 取得した代表色を許容範囲選択の基準にします。

## 選択マスク

- 取得した元色に十分近いピクセルを画像全体から選択します。
- 近さの閾値をライブ更新できる許容範囲として公開します。
- 離れた複数領域を1つの色変更へ含められます。
- 追加ブラシと除外ブラシを提供します。
- ブラシサイズと硬さを調整できます。
- マスクを色付きオーバーレイとして表示／非表示にできます。
- マスクは画像座標で保持し、ズーム、パン、回転、将来のレイヤー化で意味が変わらないようにします。

## 色変換

- 各変更は変更後の色と0〜100%の塗装強度を持ちます。
- 0%では見た目を変更せず、100%では選択部分を変更後の色へ近づけます。
- 変更後の色の明るさを基準にしつつ、元画像の相対的なハイライト、影、質感を保ちます。
- 同じ元画像と設定からは決定論的な結果を得ます。
- 色差計算と変換に使う色空間は実装判断とし、リリース前に画像フィクスチャで検証します。

## 変更操作のモデル

各色変更は、少なくとも次の情報を持つ非破壊操作です。

- 元色サンプリング情報
- 許容範囲
- マスクと追加／除外編集
- 変更後の色
- 塗装強度
- 表示名または安定した識別子
- 作成順または適用順

変更は一覧順に合成します。ユーザーは変更を編集、表示切替、削除、ドラッグによる並べ替えができます。元画像は書き出しまで変更しません。

## 書き出し

- PNGまたはJPEGを書き出します。
- JPEGでは品質を調整できます。
- 可能な場合、JPEG入力はJPEG、PNG／WebP入力はPNGを初期値にします。
- 元ファイル名に `-colored` を付け、選択した拡張子を使用します。
- 元ファイルを上書きしません。
