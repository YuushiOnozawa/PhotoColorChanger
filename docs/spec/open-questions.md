# 実装前の保留事項

承認済みの製品動作を変更しない、実装上の未決定事項です。

- 色差計算に使う色空間と許容範囲の対応を決める。
- 色変換式を決め、代表的なプラモデル画像フィクスチャで検証する。
- alpha、ICCプロファイル、メタデータを出力時に保持、正規化、削除のどれにするか決める。
- 対応ブラウザと画像形式の機能検出方法を決める。
- 画像処理をメインスレッド、OffscreenCanvas、Web Workerのどこで行うか決める。
- 4096px上限以外のメモリ量と処理時間の上限を決める。
- 採用するデコーダで利用できる破損画像・巨大展開画像対策を決める。
- フィクスチャのライセンスとCIで使う画像差分の許容値を決める。
- 線画オーバーレイを実装するときの抽出方式とUIを決める。
- 将来の塗料データセットのスキーマ、出典、ライセンス、更新手順を決める。
